# Accent Lab — установка и подключения

## Что нужно, а что по желанию

| Сайт | Зачем | Обязательно? |
|---|---|---|
| **github.com** | Здесь лежит само приложение (GitHub Pages). Уже подключено. | Да |
| **portal.azure.com** | Microsoft Azure Speech: точная оценка каждого звука, беглости и интонации. | Нет |
| **dash.cloudflare.com** | Маленький сервер, который хранит ключ Azure в секрете и выдаёт приложению временный пропуск. Нужен только вместе с Azure. | Только для Azure |

Без Azure и Cloudflare приложение работает полностью: модель произношения звучит, все задания записываются, а слова и тексты проверяются **прямо на телефоне** встроенным распознавателем речи. Он загружается один раз (около 100 МБ) при первой записи. Azure добавляет оценку по звукам: какой звук получился вместо нужного, беглость, интонацию.

## 1. Установить на iPhone

1. Откройте адрес приложения в **Safari**.
2. «Поделиться» → **На экран «Домой»** → **Добавить**. Переключатель «Открыть как веб-приложение» можно оставить включённым: теперь запись работает и так.
3. Откройте приложение с иконки, начните любое задание с записью и разрешите доступ к **микрофону**.
4. Первая запись скачивает распознаватель речи (около 100 МБ, один раз). Лучше сделать это по Wi-Fi: Settings → On-device speech model → **Download now**.
5. Чтобы заниматься без интернета: Settings → Offline use → **Sounds course** и при желании **All 100 texts**.

Если звук не слышно, проверьте громкость. На iOS 16 и старше звук из приложения может глушиться переключателем «Без звука» сбоку телефона.

## 2. Подключить Azure (по желанию)

### 2.1. Ключ Azure Speech (portal.azure.com)

1. Зайдите на https://portal.azure.com и создайте учётную запись Microsoft. Azure попросит телефон и банковскую карту для проверки личности. Бесплатный тариф ничего не списывает.
2. Вверху в поиске наберите **Speech** и выберите сервис **Speech** (иногда он называется «Azure AI Speech» или «Speech service»).
3. Нажмите **Create** и заполните форму:
   * **Subscription**: ваша подписка (например, Azure subscription 1);
   * **Resource group**: **Create new** → `accent-lab`;
   * **Region**: **East US**;
   * **Name**: любое уникальное имя, например `accent-lab-speech-123`;
   * **Pricing tier**: **Free F0** (5 часов распознавания в месяц бесплатно). Если F0 нельзя выбрать (он уже есть в этой подписке), выберите **Standard S0** с оплатой только за использованные минуты.
4. **Review + create** → **Create**. Через минуту нажмите **Go to resource**.
5. Слева откройте **Resource Management → Keys and Endpoint**. Скопируйте **KEY 1** и **Location/Region** (для East US это `eastus`).

Ключ никому не отправляйте и не вставляйте в само приложение. Он нужен только на следующем шаге.

### 2.2. Сервер токенов (dash.cloudflare.com, бесплатно)

1. Зарегистрируйтесь на https://dash.cloudflare.com (карта не нужна).
2. Слева **Workers & Pages** → **Create application** → **Start with Hello World!** (или **Create Worker**) → придумайте имя, например `accent-lab-token` → **Deploy**.
3. На странице воркера нажмите **Edit code**. Удалите весь код в редакторе, вставьте содержимое файла `server/token-worker.js` из этого репозитория и нажмите **Deploy**.
4. Вернитесь к воркеру: **Settings → Variables and Secrets → Add**. Добавьте три переменные и затем нажмите **Deploy**:
   * `AZURE_SPEECH_KEY`, тип **Secret**, значение: KEY 1 из Azure;
   * `AZURE_REGION`, тип **Text**: `eastus`;
   * `ALLOWED_ORIGINS`, тип **Text**: адрес вашего сайта без пути, например `https://имя-пользователя.github.io`.
5. Скопируйте адрес воркера вида `https://accent-lab-token.<ваше-имя>.workers.dev`. Он есть на странице воркера.

### 2.3. В приложении

Settings → Speech checking → **Automatic** (или **Azure pronunciation assessment**) → вставьте адрес воркера в поле «Azure token server address» → **Save and test**. Должно появиться «Connected. Region: eastus.» После этого все записи проверяет Azure, в любом браузере.

## Что и чем измеряется

* **On-device recognition** (без подключений). Одиночное слово сравнивается со словами, с которыми его обычно путают («sheep» или «ship»), и результат приводится к тому, как распознаётся эталонная запись. Предложения и тексты распознаются целиком и сверяются с текстом по словам. Отдельные звуки, ударение и интонацию этот режим не оценивает и прямо об этом пишет. Для немногих слов, которые распознаватель не уверенно узнаёт даже в эталоне, приложение не ставит балл, а предлагает сравнить запись на слух.
* **Browser speech recognition**: распознаватель Chrome, Edge или Safari. Показывает слова прямо во время чтения, но нужен интернет, а в части браузеров (Firefox, Brave, Opera, приложения с экрана «Домой» на iPhone) его нет. Если он не сработал, ту же запись автоматически проверяет распознаватель на телефоне.
* **Azure**: точность каждого звука, звук, похожий на произнесённый, точность слов, гласных и согласных, беглость, полнота, просодия. Ритм и интонация оцениваются по просодии (помечены Estimated). Ударение в слове и связная речь отдельно не измеряются (Not measured).
