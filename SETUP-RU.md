# Accent Lab — установка и настройка

## 1. Опубликовать приложение (GitHub Pages, бесплатно)

1. На GitHub создайте **публичный** репозиторий, например `accent-lab`. На бесплатном тарифе GitHub Pages работает только с публичными репозиториями.
2. Загрузите в него **содержимое папки `dist`** (не саму папку): файлы `index.html`, `sw.js`, `manifest.webmanifest` и папки `assets`, `audio`, `data`, `icons`, `splash`.
   * Файлов около 330, а веб-интерфейс GitHub принимает до 100 файлов за одну загрузку. Удобнее загрузить всё через приложение GitHub Desktop или попросить Claude отправить файлы в репозиторий.
3. В репозитории откройте Settings → Pages → Build and deployment → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет доступен по адресу `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/accent-lab/`.
   * В адресе стоит имя пользователя GitHub. Если в нём есть ваши имя и фамилия, используйте другой аккаунт или переименуйте его.

## 2. Установить на iPhone

1. Откройте адрес сайта в **Safari**.
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой) → **На экран «Домой»** → выключите переключатель **«Открыть как веб-приложение»** (на iPhone проверка речи работает только в Safari) → **Добавить**.
3. Запустите приложение с иконки и разрешите доступ к микрофону.
4. Для базовой проверки речи на iPhone должна быть включена диктовка: Настройки → Основные → Клавиатура → Включить диктовку.
5. Чтобы всё работало без интернета: Settings → **Download everything** (около 150 МБ). Для проверки произношения интернет всё равно нужен.

## 3. Подключить точную проверку произношения (Azure, по желанию)

Без этого шага приложение проверяет только, распознано ли каждое слово. С Azure появляются оценки каждого звука, подсказка, какой звук получился вместо нужного, беглость и интонация.

**3.1. Ключ Azure Speech**
1. Зарегистрируйтесь на https://portal.azure.com (нужна банковская карта для проверки личности).
2. Create a resource → **Speech** (Azure AI Speech). Выберите регион, например `East US`, и тариф **Free F0**, если он доступен.
   На бесплатном тарифе даётся 5 часов распознавания в месяц. Проверьте в Azure, что Pronunciation Assessment работает на F0 в вашем регионе. Если нет, выберите Standard S0 с оплатой по факту.
3. В ресурсе откройте Keys and Endpoint и скопируйте **KEY 1** и **Location/Region** (например `eastus`).

**3.2. Сервер токенов (Cloudflare Workers, бесплатно)**
Ключ нельзя хранить в самом приложении, поэтому нужен маленький сервер. Он отдаёт приложению временный токен на 10 минут.
1. Зарегистрируйтесь на https://dash.cloudflare.com → Workers & Pages → Create → **Create Worker** → Deploy.
2. Edit code → вставьте содержимое файла `server/token-worker.js` → Deploy.
3. Settings → Variables and Secrets → добавьте:
   * `AZURE_SPEECH_KEY` — тип **Secret**, значение KEY 1;
   * `AZURE_REGION` — например `eastus`;
   * `ALLOWED_ORIGINS` — `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io`.
4. Скопируйте адрес воркера, например `https://accent-token.ИМЯ.workers.dev`.

**3.3. В приложении**
Settings → Pronunciation assessment → **Azure** → вставьте адрес воркера → **Save and test**. Должно появиться «Connected».

## Что измеряется

* **Basic word recognition**: понятность (каждое ли слово распознано как нужное) и темп речи. Звуки, ударение и интонацию этот режим не оценивает, и приложение прямо это показывает.
* **Azure**: точность каждого звука, звук, похожий на произнесённый, точность слов, гласных и согласных, беглость, полнота, просодия. Ритм и интонация — оценки на основе просодии (помечены Estimated). Ударение в слове и связная речь отдельно не измеряются (Not measured).
